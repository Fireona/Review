Breakdown of terms for functions, strings, etc. 

                        JavaScript Simplest Function
                    
                        function makeCoffee() {
                            console.log("Brewing coffee...");
                        }
    function
  • Defines what should happen when the function is called. Similar to a set of instructions to a recipe. The example has a function called makeCoffee and all code starting from the opening parantheses ((...) to the closing curly brackets (...}) are considered to be part of said function.

    • Function name
  • A label for the task to be performed. Here, the task is called makeCoffee since the function is about making coffee. Marked in the example with:
    makeCoffee

    • Parantheses ()
  • A location to store parameters (inputs our function accepts). They can be empty as well if not needed.
  • A signal to start performing the function the moment the name of the function is called. A trigger when the name of a function pops up.

    • Function body {...}
  • The main body of a function is inside {}. Inside will be the list of tasks to undertake when called. Marked in the example with:
    { console.log("Hello!"); }

    • console.log
  • A built-in method; A function that belongs to the console object.
  • Prints information to the console (a place where you can see messages or output from your code).
  • Used to display something. Similar to writing a note on a chalkboard while our code runs.

    • "Calling" or "Invoking"
  • A command given to JavaScript to run the called function (usually by function name). 

    • JavaScript Argument and Parameters
                    
                        function greet(name) {
                            console.log("Hello, " + name + "!");
                        }

                        greet("Sam");
    Parameter
  • A parameter is a field that takes the input and is used into in the function. The parameter here would be name.

    • Argument
  • The actual value we feed into the function when called. The argument here is "Sam". 

    • Return Values
                    
                        function add(a, b) {
                            return a + b;
                        }

                        let sum = add(2, 3);
                        console.log(sum)
    Return
  • Sends a value back to whoever called the function. Marked in the example with:
    return a + b
    • Variable
  • A named "box" that stores a value. Marked in the example with:
    let sum = ...
    • Function Expression 
    JavaScript
                    
                        const sayHi = function () {
                            console.log("Hi!");
  • Function stored inside a variable. Typically has no name and is "anonymous". Marked in the example with:
    const sayHi = function() {}.
    • Arrow Function 
    JavaScript
                    
                        const sayHi  = () => {
                            console.log("Hi!");
  • Shorter way of writing a function and more common in modern JavaScript. Marked in the example with:
    () => {}
    • Anonymous Function
  • An anonymous function is a function without a name and is often used in other code. Marked in the example with:
    function() {}.
    • Methods and Objects 
                        
                        const person = {
                            name: "Alex";
                            greet: function() {
                                console.log("Hi, I'm " + this.name);
                            }
                        };

                        person.greet();
    Object
  • Container for related data and functions. Marked in the example with:
    { name: "Alex", greet: function() { ... }}
    • Property
  • A piece of data stored in an object. Marked in the example with:
    name: "Alex"
    • Method
  • A function inside an object. Marked in the example with:
    greet: function() { ... }
    • This
  • Refers to the current object. Marked in the example with:
    this.name
    • Statement ;
  • A single instruction. Typically ends with ;
    • Scope
  • Where a variable or function can be used or seen.
    • Declaration
  • Creating something new (like a variable or function). Example:
    function greet() {}
    • Expression
  • Any bit of code that produces a valuel. Examples:
    2 + 2; "Hello" + "World";
    • Execution
  • The computer actually running the code, or "calling" a function.
    • Syntax
  • Grammar rules of the language.
    • Callback
  • A function passed into another function to be run later. Example:
    setTimeout(() => console.log("Done"),1000);

Analogies

  • A function is akin to a complete recipe.
  • A parameter is a placeholder ingredient. ("Add __ cups of sugar").
  • An argument is the actual ingredient you use. ("Add 2 cups of sugar").
  • A return value is the finished dish.
  • A method is a recipe that belongs to a specific chef (object).
  • An expression is a mini recipe that creates a value ("mix flour + water").
  • A call is when you make the recipe.
