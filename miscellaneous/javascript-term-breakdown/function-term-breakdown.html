Breakdown of terms for functions, strings, etc. 

                        
                        function makeCoffee() {
                            console.log("Brewing coffee...");
                        }
    function
  • Defines what should happen when the function is later called. Similar to a set of instructions to a recipe.

    • Function name
  • A label for the task to be performed. Here, the task is called makeCoffee since the function is about making coffee. makeCoffee is the function name.

    • Parantheses ()
  • A location to store parameters (inputs our function accepts). They can be empty as well if not needed.
  • A signal to start performing the function the moment the name of the function is called. A trigger when name of function pops up.

    • Function body {...}
  • The main body of a function is inside {}. Inside will be the list of tasks to undertake when called.

    • console.log
  • A built-in method; A function that belongs to the console object.
  • Prints information to the console (a place where you can see messages or output from your code).
  • Used to display something. Similar to writing a note on a chalkboard while our code runs.

    • "Calling" or "Invoking"
  • A command given to JavaScript to run the called function (usually by function name). 

    •                     
                        function greet(name) {
                            console.log("Hello, " + name + "!");
                        }

                        greet("Sam");
    Parameter
  • A parameter is a field that takes the input and is used into in the function. The parameter here would be name.

    • Argument
  • The actual value we feed into the function when called. The argument here is "Sam".
